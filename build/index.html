How it works

One local path from folder to evidence.

The pipeline preserves document structure so a useful result still knows where it came from.

  1. 01

    Choose a folder

    Only directories you select enter the collection.

  2. 02

    Parse its structure

    TXT, Markdown, and HTML become headings, paragraphs, lists, code, and tables.

  3. 03

    Build a local index

    Deterministic chunks are written atomically on your device.

  4. 04

    Ask or search

    BM25 finds relevant passages without an API or network.

  5. 05

    Follow the citation

    Inspect the exact passage, then open its indexed file.

HTML support extracts structured text. It does not reproduce the page layout, and script, style, noscript, and SVG content are excluded.

Privacy boundary

Local is an architecture, not a badge.

The current build has no code path that makes a network request. The desktop renderer is separately prevented from reaching the network or filesystem directly.
